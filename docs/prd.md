# 웹 초대장 제작 서비스 PRD

## 핵심 목표

정보를 입력하면 모바일 웹 초대장을 만들고, 링크로 공유해 참석 여부를 받는 서비스다.

## 사용자

- 호스트: 초대장을 만들고 공유하며 응답을 확인한다.
- 게스트: 초대장을 보고 참석 여부를 제출한다.
- 로그인 없이 링크로 사용한다.

## 경로

### `/create`

호스트가 제목, 일시, 장소, 본문을 입력한다. 입력 내용은 미리보기로 확인할 수 있으며, 발행 뒤 초대장 링크와 응답 현황 링크를 복사할 수 있다.

### `/i/[id]`

게스트가 초대장을 보고 이름, 참석 여부, 동반 인원을 제출한다. 제출이 끝나면 같은 화면에서 완료 상태를 표시한다.

### `/i/[id]/responses`

호스트가 응답 현황 링크의 키로 접근한다. 응답 목록, 참석 수, 불참 수, 참석 인원 합계를 확인한다.

## MVP 기능

- 제목·일시·장소·본문 입력과 실시간 미리보기
- 추측하기 어려운 고유 ID로 초대장 발행
- 초대장 링크와 응답 현황 링크 복사
- 장소를 텍스트 주소로 표시
- 이름·참석 여부·동반 인원 제출
- 제출 후 완료 상태 표시
- 응답 목록과 참석·불참 수, 참석 인원 합계 표시

## 데이터와 계산 기준

- 초대장은 제목, 일시, 장소, 본문, 고유 ID, 응답 현황 접근 키를 가진다.
- 응답은 이름, 참석 여부, 동반 인원 수를 가진다.
- 동반 인원은 응답자 본인을 제외하고 함께 참석하는 사람 수다.
- 참석 인원 합계는 참석 응답자 수와 참석 응답의 동반 인원 수를 더해 계산한다.
- 현재 데이터는 프로젝트 루트의 `.data/invitations`에 파일로 저장한다.

## 제외 범위

- 로그인
- 결제
- 네이티브 앱
- 드래그 편집
- 축의금 송금
- AI 생성
- 다국어

## 기존 커스텀 PRD와 달라지는 부분

- 기능 범위는 기존 문서와 같다.
- 실습자료 기준으로 제목, 사용자 역할, 경로별 책임, 데이터·계산 기준을 명확히 정리했다.
- 실제 구현에 있는 응답 현황 접근 키와 `.data/invitations` 파일 저장 방식을 문서에 반영했다.
